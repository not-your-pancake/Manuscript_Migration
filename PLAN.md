# Migration plan — TCC manuscript → Springer `sn-jnl` (Climatic Change)

Status: **plan only. Nothing has been migrated.** `new/` is empty.

Source of truth for text: `old/manuscript/manuscript.tex` (elsarticle, 1881 lines).
Target: `new/main.tex` on `\documentclass[sn-basic]{sn-jnl}`.

---

## 1. Target file layout in `new/`

```
new/
  main.tex                 <- manuscript body, blinded
  title_page.tex           <- separate, NOT compiled into main.tex
  references.bib           <- byte-identical copy of old/manuscript/references.bib
  sn-jnl.cls               <- copied from template/
  sn-basic.bst             <- copied from template/
  tables/                  <- 6 .tex table bodies, copied verbatim
  figures/                 <- the 8 used .png files, copied
```

`.cls` and `.bst` sit next to `main.tex` (CLAUDE.md requirement). Figures are
copied into `new/figures/` so `new/` is self-contained and no `../` path escapes
the folder; `\graphicspath{{figures/}}` replaces `{{../outputs/figures/}}`.

## 2. Ordered steps

1. Copy `sn-jnl.cls`, `sn-basic.bst`, `references.bib`, `tables/*.tex`, and the
   8 referenced `.png` files into `new/`. Compile a stub `main.tex` (preamble +
   title + abstract only) to prove the class works before any text moves.
2. Preamble. Class line becomes `\documentclass[pdflatex,sn-basic]{sn-jnl}`.
   Drop the six `\setlength` page-geometry overrides — `sn-jnl` sets Springer's
   trim size and those lines will fight it. Keep `\newcommand{\degC}`. Keep
   `graphicx`, `booktabs`, `amsmath`, `amssymb`, `array`, `url`. Drop `lineno`
   as a package (`sn-jnl` provides `lineno` itself; turn numbering on with the
   class's own mechanism and verify in the log). Drop `\journal{Urban Climate}`.
3. Front matter. `\title{...}`, `\abstract{...}`, `\keywords{...}` in `sn-jnl`
   syntax. Abstract text copied character-for-character. Keywords are currently
   8, separated by `\sep`; they become comma-separated — **and 8 exceeds the
   4–6 limit, so which two to drop is your call, not mine.**
4. Blinding. Everything in §5 below is cut out of `main.tex` and moved into
   `title_page.tex` verbatim.
5. Body. Move section by section, in order, verbatim: Introduction → Literature
   Review → Materials and Methods → Results → Discussion → Conclusion. Compile
   after each section.
6. Floats. Figure and table *environments* move to the end of `main.tex` (after
   the references, before or after Statements and Declarations per the journal's
   layout), while the captions stay in the main text as required. Concretely:
   caption text is not reworded, only relocated with its float.
7. Bibliography. Replace the 708-line inlined `thebibliography` block with
   `\bibliographystyle{sn-basic}` + `\bibliography{references}`, and run the
   4-pass build. The `.bib` is copied unchanged.
8. Add "Statements and Declarations" after the references (competing interests,
   funding, author contributions, data availability), sourced verbatim from the
   existing Declaration of competing interest / Data availability / CRediT text
   — minus the identifying URLs, which move to the title page.
9. Commit after every successful compile.

## 3. What I expect to break, and why

**A. Citation rendering flips from `[1]` to `(Shaw et al. 2022)`.**
The compiled `old/manuscript/manuscript.pdf` renders numbered citations. Under
`sn-basic` they become author–year. This is the required end state, but it
changes line breaks and page count everywhere, and it changes how `\citet`
sentences read in print. No text edit is involved; the words are the same.

**B. The reference list is currently hard-coded, not generated.**
`old` ships 708 lines of `\bibitem` with `\bibinfo{...}`, `\DOIprefix`,
`\newblock` — elsarticle-specific markup. `sn-basic.bst` will not accept it.
The list must be regenerated by BibTeX from `references.bib`. Risk: the
regenerated list will not be textually identical to the inlined one (different
punctuation, DOI presentation, author-name abbreviation). Field content comes
from the `.bib`, which I will not touch. **Any entry whose inlined `\bibitem`
was hand-corrected without the fix being pushed back into `references.bib` will
silently regress.** I have not diffed all 68 entries against the 73 `.bib`
entries; if you want that diff, say so and I will produce it before migrating.

**C. `\bibitem` count (68) ≠ `.bib` entry count (73).** 6 `.bib` entries are
never cited and will vanish from the regenerated list; `hunter1999` has an
inlined `\bibitem` but is never cited either. Under BibTeX the printed list will
therefore be **67 entries, not 68**. That is a real change to the reference list
and I am flagging it rather than fixing it.

**D. `\frontmatter` structure is incompatible.** `elsarticle`'s
`\begin{frontmatter}`, `\author[bup]{}`, `\ead{}`, `\affiliation[bup]{}`,
`\cortext[cor1]{}`, `\corref{}`, `\begin{keyword}...\sep...` have no meaning in
`sn-jnl`. All of it is rewritten into `\author*[1]{\fnm{}\sur{}}`, `\email{}`,
`\affil[1]{\orgdiv{}\orgname{}\orgaddress{}}` — but that rewritten block goes in
`title_page.tex`, not `main.tex`.

**E. Page geometry.** The six `\setlength` lines (`\textwidth 18cm`,
`\oddsidemargin -1cm`, …) were tuned for a wide Elsevier review layout. Kept,
they will overflow the Springer trim and produce `Overfull \hbox` on nearly
every page. Dropped, the double-column-ish Springer measure is narrower, so the
wide tables are the next problem —

**F. Tables will overflow.** `table_catdist.tex` (1188 bytes) and
`table_validation.tex` (765 bytes) were laid out for an 18 cm text width. On
`sn-basic` they will run into the margin. The fix is presentational only
(`\small`, `\resizebox`, or `table*`), never a change to a single number. I will
show you the overfull warnings before choosing.

**G. Figure sizing.** All 8 figures are `\includegraphics[width=\linewidth]` or
`0.72–0.85\linewidth` PNGs at 150 dpi, 1012–2511 px wide. At Springer's narrower
measure, 150 dpi renders acceptably but the label text inside the map panels
(`map_projected_means.png`, 2511×2081) will shrink and may become unreadable.
That is a regeneration problem in the plotting pipeline, not something I can fix
in LaTeX.

**H. `\linenumbers`.** `sn-jnl` and `lineno` interact badly if `lineno` is loaded
twice. Expect a `Command \linenumbers already defined` or silently absent line
numbers on the first compile.

**I. Word limit.** The manuscript is roughly **4,200 words over** the 10,000
limit once the figure/table surcharge is applied (see the audit). Migration does
not change this. Cutting is a decision for you.

**J. Non-ASCII in author data.** `Ivan Grgić` contains `ć`. It survives in
`title_page.tex` under pdflatex only if the encoding is declared. Minor, but it
will show up as a compile error, not a wrong glyph.

**K. `[cite: 1]` contamination in `template/sn-article.tex`.** That file is a
prior half-finished migration attempt with 159 `[cite: 1]` artifacts injected
into the prose. **I will not copy any text from it.** All text comes from
`old/manuscript/manuscript.tex`. Flagged so nobody reuses it by mistake.
